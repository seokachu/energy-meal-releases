# Energy Meal 🍚

사주 컨셉으로 "오늘의 기운"을 읽고, 아침 · 점심 · 저녁 시간대에 맞는 한 끼를 추천하는 하이브리드 웹앱

## 소개

생년월일 · 태어난 시간(십이시) · 성별 · 양력/음력을 입력하면, 사용자의 "기운"을 해석해 시간대별 오늘의 메뉴를 추천합니다. 서버 없이 동작하는 100% 클라이언트 사이드 앱으로, 사용자 데이터는 브라우저 localStorage에만 저장됩니다.

- **시간대별 추천** — 접속 시각에 따라 아침/점심/저녁 탭이 기본 선택되고, 시간대별 후보군(총 305개 메뉴, 한식·분식·중식·일식·양식·아시안)에서 추천
- **요리별 개별 이미지** — 269종의 AI 푸드 포토그래피 이미지(메뉴별 개별 컷, 통일된 톤) + 이미지 평균 색상에서 추출한 배경 팔레트
- **다시 추천하기** — 추천 순환 + 이미지 프리로드로 플리커 없는 전환
- **안주 페어링** — 소주 · 맥주 · 와인 · 막걸리 · 위스키 · 사케에 맞춘 안주 추천과 나이트 모드 UI
- **PWA** — 홈 화면 설치, 서비스워커 오프라인 폴백 지원
- **하이브리드** — Expo(React Native) WebView 셸에 임베드 시 이를 감지해 전체 화면 레이아웃으로 전환

## 설치

### 웹

별도 설치 없이 브라우저에서 바로 쓸 수 있습니다. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

### 안드로이드

[릴리즈 페이지](../../releases)에서 최신 APK를 내려받아 설치하세요.

> **APK로 설치하신 경우** — 추후 Google Play 버전으로 옮기실 때는 기존 앱을 삭제한 뒤 다시 설치하셔야 합니다. Play 스토어 배포본과 서명이 달라 덮어쓰기 업데이트가 되지 않습니다.

### iOS

App Store를 통해서만 설치할 수 있습니다.

## 개인정보

에너지밀은 **입력하신 정보를 서버로 보내지 않습니다.** 생년월일과 태어난 시각은 기기 안에만 저장되고, 사주 계산도 기기 안에서 이루어집니다. 계정도 로그인도 없습니다.

자세한 내용은 [개인정보처리방침](docs/privacy.md)을 참고해주세요.
