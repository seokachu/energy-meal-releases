# 에너지밀 — 오늘의 기운 한끼

사주 오행을 바탕으로 오늘 나에게 맞는 아침·점심·저녁 메뉴를 추천하는 앱입니다.

**웹에서 바로 사용하기 → [energy-meal-hybrid.vercel.app](https://energy-meal-hybrid.vercel.app/)**

---

## 이 저장소는

에너지밀의 **릴리즈 배포와 사용자 지원**을 위한 공간입니다. 앱 소스 코드는 포함되어 있지 않습니다.

- **[릴리즈](../../releases)** — 버전별 변경사항과 안드로이드 APK
- **[문의·버그 신고](../../issues)** — 이슈로 남겨주시면 확인합니다
- **[개인정보처리방침](docs/privacy.md)**

## 무엇을 하는 앱인가요

생년월일과 태어난 시각을 입력하면 만세력으로 사주를 세우고, 오행(목·화·토·금·수)의 균형을 계산합니다. 부족한 기운을 채워주는 음식을 끼니마다 하나씩 추천합니다.

- 아침·점심·저녁 시간대별 추천
- 하루 한 번 고정 — 자정이 지나면 새로운 메뉴
- 끼니 시간에 맞춘 알림 (07:30 · 11:30 · 17:30)
- 안주 페어링 — 술자리를 위한 별도 추천

## 설치

### 웹

별도 설치 없이 브라우저에서 바로 쓸 수 있습니다. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

### 안드로이드

[릴리즈 페이지](../../releases)에서 최신 APK를 내려받아 설치하세요.

> **APK로 설치하신 경우** — 추후 Google Play 버전으로 옮기실 때는 기존 앱을 삭제한 뒤 다시 설치하셔야 합니다. Play 스토어 배포본과 서명이 달라 덮어쓰기 업데이트가 되지 않습니다.

### iOS

App Store를 통해서만 설치할 수 있습니다.

## 개인정보

에너지밀은 **입력하신 정보를 서버로 보내지 않습니다.** 생년월일과 태어난 시각은 기기 안에만 저장되고, 사주 계산도 기기 안에서 이루어집니다. 계정도 로그인도 없습니다.

자세한 내용은 [개인정보처리방침](docs/privacy.md)을 참고해주세요.
